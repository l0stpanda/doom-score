# Cleanup plan (pre cross-league phase)

Branch `cleanup/pre-cross-league`. Goal: keep only what the pipeline, the viz and the cross-league comparison need;
archive history; delete only regenerable or dead files. No model, label or feature changes.

**Before:** 127 tracked files (123 in `ADAM-DATA/`), 11.79 MB tracked.

**Summary of actions (tracked files):** keep 84, move 3, archive 33 (`git mv` to `ADAM-DATA/archive/`, reasons in
`archive/README.md`), delete 4, leave 3 (not mine / unclear).

## Code changes planned (no behaviour change)

- One shared `lpct()` (within-league-season percentile) in `src/common.py`, replacing four identical copies
  (`build_crosswalk.py`, `build_slim.py`, `m1b_features.py`, `model/backtest.py`). The two `pct_rank()` copies in
  `build_phase1.py` / `phase2_api_features.py` divide by all rows rather than non-missing rows, so they are
  **not** merged.
- Remove unused imports/variables found by pyflakes: `fetch_phase2.py` (`f1`), `fetch_phase3.py` (`f1`),
  `fetch_phase4.py` (`S`), `parse_front_office.py` (`pd`), `build_crosswalk.py` (`lp`), `viz/fetch_logos.py` (`e`).
- Generated docs move out of the folder root: `build_slim.py` → `reports/slim_selection.md`,
  `build_crosswalk.py` → `reports/feature_crosswalk.md`, `run_m3.py` → `reports/model_card.md`. Text references to
  `DECISIONS.md` point to `docs/decisions_full.md`.
- `requirements.txt`: every pinned package is imported somewhere (numpy, pandas, scipy, scikit-learn, requests,
  matplotlib, interpret-core, lightgbm, plotly); nothing to drop.
- No dead functions found (every `def` is referenced). No overlapping scripts are merged: the fetch/build scripts
  are separate pipeline steps, and the model scripts import each other.
- New single entry point `scripts/build_all.py` (step 3).

## Not in the repo (local only)

- Delete: `__pycache__/` folders and the stray `ADAM-DATA/tests/` folder (contains only `__pycache__`; there is no
  test suite).
- Leave: `ADAM-DATA/data/raw/` (git-ignored cache). Several folders there (`bbref_*`, `hockey_reference`, `census`,
  `nhl_records_api`, parts of `mlb_statsapi`/`nhl_stats_api`) came from an earlier untracked downloader; the tracked
  phase 1–4 fetch scripts use other cache names (`mlb_standings`, `nhl_player_stats`, `wikipedia_money`, …) that are
  **not** on this machine. So `build_all --from-raw` would refetch from the network.
- Leave: `.venv/`, `dashboard/assets/logos/`, `dashboard/doom_scatter.html` (git-ignored, D105).
